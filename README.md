## ✨ Features

- **Phase-wise Structure** — Roadmap divided into clear learning phases from Foundation to Advanced AI Engineering
- **Interactive Progress Tracking** — Check off topics as you complete them; progress is saved locally
- **Visual Timeline Layout** — Clean, readable timeline view showing the full learning journey at a glance
- **Curated Resources** — Each phase links to hand-picked learning resources (docs, courses, tools)
- **Fully Offline** — Single HTML file, no dependencies, runs anywhere

## 🗺️ Roadmap Phases

| Phase | Focus |
|---|---|
| Phase 0 | Foundation — Python, SQL, AI Coding |
| Phase 1 | Data & Math — NumPy, Pandas, Statistics, Linear Algebra |
| Phase 2 | Core ML — Scikit-learn, Supervised/Unsupervised Learning |
| Phase 3 | Deep Learning — Neural Networks, PyTorch/TensorFlow |
| Phase 4 | AI Engineering — LLMs, APIs, Deployment, MLOps |
